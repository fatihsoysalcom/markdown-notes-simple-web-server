# Markdown Notes Simple Web Server

This Python example demonstrates how to build a simple, database-free note application. It uses a minimal HTTP server to read Markdown files from a 'notes' directory, convert them to HTML, and serve them dynamically. This approach allows users to manage notes as plain text files without complex database dependencies.

## Language

`python`

## How to Run

1. Save the code as `notes_server.py`.
2. Install the `markdown` library: `pip install markdown`
3. Run the script: `python notes_server.py`
4. Open your browser to `http://localhost:8000`
